# User stories

## Change my username

As a player, I can change my username by clicking my username in the players list, typing a new username, and submitting it.

Done when:

- Clicking my own name in the players list opens a text field. Other players' names are not editable.
- Pressing Enter, or leaving the field, submits the name.
- A non-empty name replaces the previous one in the players list, still marked as me.
- Reloading the page in the same browser shows the new username.
